Cesium 3D Unemployment Map
Description

Cesium Globe App is a browser-based interactive 3D map that visualizes county-level U.S. unemployment data. Leveraging CesiumJS, this project merges raw labor statistics with geospatial boundaries to provide an engaging, color-coded (choropleth) globe where users gain a spatial and temporal perspective on employment trends nationwide.

Core Features
  • Data Transformation & Integration: Automated CSV data ingestion from Bureau of Labor Statistics with conversion to optimized JSON format
  • Dynamic Choropleth Visualization: 3D globe rendering with counties shaded by unemployment rate and state extrusion on selection
  • User Interaction & Exploration: Intuitive globe navigation (zoom, rotate, pan) with year/time selector for trend comparison
  • Performance & Data Handling: Efficient loading of high-resolution geospatial data with prefetching and caching mechanisms
Technical Stack
  • Frontend: HTML, JavaScript (CesiumJS, D3.js for data handling and visualization)
  • Data Processing: Client-side scripts converting CSV to JSON with geospatial enrichment
  • Mapping Engine: CesiumJS for real-time 3D globe rendering
  • Deployment: Static web deployment, CDN-ready
Key Integrations
  • Bureau of Labor Statistics: Official U.S. unemployment data source
  • U.S. Census Bureau/GeoJSON: Authoritative county-level boundary data
  • CesiumJS: Advanced 3D geospatial visualization engine
